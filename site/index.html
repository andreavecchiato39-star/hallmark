Configurazione Active Directory Single Sign-On (SSO)

Istruzioni tecniche per legare l'applicazione all'autenticazione Kerberos/NTLM su IIS Windows Server.

1. Passaggio Credenziali Windows da IIS

Su **IIS (Internet Information Services)** abilitare **Windows Authentication** e disabilitare *Anonymous Authentication* nelle impostazioni del sito web Intranet:

IIS Manager -> Authentication -> Windows Authentication: ENABLED

Con questa configurazione, IIS passerà automaticamente l'header Server Variable LOGON_USER / AUTH_USER contenente il formato ADCOMPOUND\nome.cognome senza richiedere alcuna password all'utente.

2. Mappatura Gruppi di Sicurezza Active Directory

I diritti di scrittura (Builder, Modifica, Import) vengono assegnati al gruppo AD:
ADCOMPOUND\SGQ_EDITORS

Tutti gli altri dipendenti appartenenti al gruppo standard:
ADCOMPOUND\DOMAIN_USERS
vengono indirizzati in automatico all'interfaccia di consultazione semplificata.
